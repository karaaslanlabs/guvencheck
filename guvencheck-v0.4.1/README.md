# GüvenCheck V0.4.1

Türkiye odaklı dijital risk analiz prototipi.

## V0.4.1
- Mesaj, link ve ekran görüntüsü analizi
- Web araştırmalı link doğrulama
- Analiz başı token / maliyet / gecikme ölçümü
- `/lab` altında 24 mesaj, 4 link ve 6 sentetik ekran görüntüsü benchmarkı
- Kritik kaçırma ve yanlış alarm sayaçları

## Environment variables
`OPENAI_API_KEY`
`OPENAI_MODEL=gpt-5.6-terra`

Lab yalnızca manuel başlatıldığında API çağrısı yapar.
